API Contract
Titip.in · REST API · Dokumen referensi untuk Android & Backend team
v1.0.0 Base URL: https://api.titip.in/v1 JWT Bearer Auth JSON · UTF-8
Global Response Format
📦 Semua response pakai wrapper yang sama
// SUCCESS { "success": true, "data": { /* object atau array */ }, "message": "OK" } // ERROR { "success": false, "error": { "code": "UNAUTHORIZED", "message": "Token expired or invalid" } } // LIST dengan pagination { "success": true, "data": [ /* array items */ ], "meta": { "page": 1, "limit": 20, "total": 87, "hasNext": true } }
🔐 Auth Header
Authorization: Bearer <access_token>
Error Codes
400
BAD_REQUEST
Request body / param tidak valid atau ada field yang missing
401
UNAUTHORIZED
Token tidak ada, expired, atau invalid
403
FORBIDDEN
User tidak punya akses ke resource ini (bukan miliknya)
404
NOT_FOUND
Resource yang diminta tidak ditemukan di database
409
CONFLICT
Data sudah ada, misal email sudah terdaftar
429
RATE_LIMITED
Terlalu banyak request dalam waktu singkat
500
SERVER_ERROR
Internal server error, perlu dicek di log backend

Auth
POST /auth/register Daftar akun baru
Request Body
{ "name": "Rizky Pratama", // required "email": "rizky@ub.ac.id", // required "password": "min8chars", // required, min 8 "waNumber": "628123456789" // required, format intl }
Response 201
{ "success": true, "data": { "accessToken": "eyJ...", "refreshToken": "eyJ...", "user": UserSummary } }
POST /auth/login Login dengan email & password
Request Body
{ "email": "rizky@ub.ac.id", "password": "password123" }
Response 200
{ "success": true, "data": { "accessToken": "eyJ...", // expires 15m "refreshToken": "eyJ...", // expires 30d "user": UserSummary } }
POST /auth/refresh Refresh access token yang expired
Request Body
{ "refreshToken": "eyJ..." }
Response 200
{ "success": true, "data": { "accessToken": "eyJ..." } }

Jastip
GET /jastip List jastip aktif, sort by distance 🔐 Auth
Query Params
ParamTypeWajibKeterangan
lat Double optional Latitude user untuk sort by distance
lng Double optional Longitude user
radius Int optional Radius filter dalam km, default: 10
page Int optional Halaman, default: 1
limit Int optional Jumlah per halaman, default: 20
Response 200
{ "success": true, "data": [JastipListing, ...], "meta": { "page": 1, "limit": 20, "total": 24, "hasNext": false } }
GET /jastip/{id} Detail satu jastip 🔐 Auth
Response 200
{ "success": true, "data": JastipListing }
POST /jastip Buat jastip baru 🔐 Auth
Request Body
{ "fromLocation": "Giant Dinoyo", // required "toLocation": "Kampus UB", // required "deadline": "2025-03-10T15:00:00Z", // required "latitude": -7.9666, // required "longitude": 112.6326, // required "notes": "Bisa groceries & snack" // optional }
Response 201
{ "success": true, "data": JastipListing }
PUT /jastip/{id} Update jastip milik sendiri 🔐 Auth
Request Body (semua optional)
{ "fromLocation": "...", "toLocation": "...", "deadline": "...", "notes": "...", "status": "CLOSED" // ACTIVE | CLOSED }
Response 200
{ "success": true, "data": JastipListing // updated }
DELETE /jastip/{id} Hapus jastip milik sendiri 🔐 Auth
Response 200
{ "success": true, "message": "Jastip deleted" }

Preloved
GET /preloved List barang preloved 🔐 Auth
Query Params
ParamTypeWajibKeterangan
category String optional FASHION, GADGET, BOOK, OTHER
condition String optional NEW, GOOD, FAIR
minPrice Long optional Filter harga minimum (IDR)
maxPrice Long optional Filter harga maksimum (IDR)
search String optional Keyword search title/desc
page Int optional Default: 1
Response 200
{ "success": true, "data": [PrelovedItem, ...], "meta": { "page": 1, "total": 89, "hasNext": true } }
POST /preloved Post barang preloved baru 🔐 Auth
Request Body
{ "title": "Nike Air Max 90", // required "description": "Jarang dipakai", // optional "price": 350000, // required, IDR "condition": "GOOD", // required "category": "FASHION", // required "images": ["s3-key-1", "s3-key-2"] // required, min 1 }
Response 201
{ "success": true, "data": PrelovedItem }
PUT /preloved/{id} Update / tandai terjual 🔐 Auth
Request Body (semua optional)
{ "title": "...", "description": "...", "price": 300000, "condition": "FAIR", "isSold": true // tandai terjual }
Response 200
{ "success": true, "data": PrelovedItem }

Request Jastip
GET /requests List semua request jastip terbuka 🔐 Auth
Response 200
{ "success": true, "data": [JastipRequest, ...] }

Response 201
{ "success": true, "data": JastipRequest }

Response 200
{ "success": true, "data": { "request": JastipRequest, // status: TAKEN "takenBy": UserSummary } }
