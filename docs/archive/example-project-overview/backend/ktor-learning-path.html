2
Coroutines, Paham Dulu Ini
⏱ 1 hari · Penting banget sebelum lanjut
Ngerti suspend fun, cara kerja coroutines, kenapa Ktor butuh ini
Konsep yang perlu dicerna
suspend fun itu apa?
Fungsi yang bisa di-pause tanpa block thread, kayak async/await tapi lebih ringan
launch vs async
launch = fire & forget, async = mau ambil return value-nya
withContext(Dispatchers.IO)
Pindahin operasi berat (DB query, network) ke thread yang tepat
Di Ktor, semua handler otomatis suspend
Jadi kalian tinggal pakai withContext buat DB ops, sisanya auto
Eksperimen kecil, jalanin ini
// Coba ini dulu di main.kt biasa import kotlinx.coroutines.* fun main() = runBlocking { println("Start") // launch: fire & forget val job = launch { delay(1000) println("Job selesai!") } // async: mau hasil returnnya val deferred = async { delay(500) "Hasil dari async" } println("Nunggu deferred...") println(deferred.await()) // ambil hasilnya job.join() // tunggu job selesai println("Semua selesai!") } // Di Ktor handler → langsung pakai: get("/test") { // ini suspend context otomatis val result = withContext(Dispatchers.IO) { // simulasi DB query delay(100) "data dari DB" } call.respond(mapOf("data" to result)) }
✅
Deliverable Phase 2
Bisa bedain launch/async, ngerti kenapa suspend fun ada, udah ga takut lihat coroutines
3
Connect Database, Exposed ORM
⏱ 2–3 hari · Ini inti backend kalian
Bisa CRUD data dari PostgreSQL, paham Exposed Table & transaction
Yang perlu dipelajari
Setup koneksi HikariCP + Exposed
Database.connect() dengan HikariDataSource
Define tabel dengan Exposed DSL
object JastipTable : Table() { ... }, mirip ORM lain tapi Kotlin-native
transaction { } block
Semua DB operation harus dalam transaction block
CRUD dengan Exposed
insert { }, selectAll(), update { }, deleteWhere { }
Flyway untuk migration
File SQL di resources/db/migration/, versioning schema
Contoh kode yang kalian tulis
// database/tables/JastipTable.kt object JastipTable : UUIDTable("jastip_listings") { val userId = reference("user_id", UsersTable) val fromLocation = varchar("from_location", 255) val toLocation = varchar("to_location", 255) val deadline = datetime("deadline") val latitude = double("latitude") val longitude = double("longitude") val notes = varchar("notes", 500).nullable() val status = enumerationByName("status", 20, JastipStatus::class) val createdAt = datetime("created_at") } // repository/JastipRepository.kt class JastipRepository { suspend fun getAll(): List<JastipDto> = dbQuery { JastipTable.selectAll() .map { it.toJastipDto() } } suspend fun create(req: CreateJastipRequest): JastipDto = dbQuery { val id = JastipTable.insertAndGetId { it[userId] = req.userId it[fromLocation] = req.fromLocation it[toLocation] = req.toLocation it[deadline] = req.deadline it[latitude] = req.latitude it[longitude] = req.longitude it[status] = JastipStatus.ACTIVE it[createdAt] = LocalDateTime.now() } JastipTable.select { JastipTable.id eq id } .single().toJastipDto() } } // utils/DatabaseFactory.kt suspend fun <T> dbQuery(block: () -> T): T = withContext(Dispatchers.IO) { transaction { block() } }
✅
Deliverable Phase 3
GET /jastip baca dari DB, POST /jastip simpan ke DB, data persist setelah restart
4
Auth, JWT Implementation
⏱ 1–2 hari
Register, login, protect endpoint dengan JWT, sama persis flow yang di API Contract
Yang perlu dipelajari
Install plugin Authentication + JWT
install(Authentication) { jwt("auth-jwt") { ... } }
Generate & verify JWT token
Pakai library JJWT, sign dengan secret key, extract claims
Protect route dengan authenticate { }
Semua route di dalam blok ini auto require JWT valid
Extract user dari token di handler
call.principal<JWTPrincipal>() untuk ambil userId dari token
Contoh kode
// plugins/Security.kt fun Application.configureSecurity() { install(Authentication) { jwt("auth-jwt") { verifier( JWT.require(Algorithm.HMAC256(secret)) .withIssuer("titip.in") .build() ) validate { credential -> if (credential.payload.getClaim("userId") .asString() != null) JWTPrincipal(credential.payload) else null } } } } // routes/JastipRoutes.kt fun Route.jastipRoutes(repo: JastipRepository) { authenticate("auth-jwt") { // 🔐 semua di sini protected get("/jastip") { // ambil userId dari token val principal = call.principal<JWTPrincipal>() val userId = principal!!.payload .getClaim("userId").asString() val jastipList = repo.getAll() call.respond(ApiResponse.success(jastipList)) } post("/jastip") { val body = call.receive<CreateJastipRequest>() val result = repo.create(body) call.respond(HttpStatusCode.Created, ApiResponse.success(result)) } } }
✅
Deliverable Phase 4
POST /auth/login return JWT, endpoint lain return 401 kalau tanpa token
