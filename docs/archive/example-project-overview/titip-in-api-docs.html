Global Response Format
✅ Success
{ "success": true, "message": "OK", "data": T, // object atau array "error": null, "meta": null }
❌ Error
{ "success": false, "message": null, "data": null, "error": { "code": "NOT_FOUND", "message": "..." }, "meta": null }
💡 Selalu cek field "success" dulu sebelum parse "data". Header Authorization: Bearer <token> wajib untuk endpoint protected.

Data Models
UserSummary reusable
{ "name": String, "waNumber": String, // "628xxx" "avatarUrl": String? }
JastipDto core
{ "id": String, // UUID "userId": String, "user": UserSummary, "fromLocation": String, "toLocation": String, "deadline": String, // ISO datetime "latitude": Double, "longitude": Double, "notes": String?, "status": "ACTIVE" | "CLOSED", "createdAt": String }

{ "id": String, "userId": String, "user": UserSummary, "title": String, "description": String?, "price": Double, // IDR "category": String, "condition": "NEW"|"LIKE_NEW"|"GOOD"|"FAIR", "imageUrl": String?, "status": "AVAILABLE"|"SOLD"|"RESERVED", "createdAt": String }

{ "id": String, "userId": String, "user": UserSummary, "fromLocation": String, "toLocation": String, "notes": String?, "status": "OPEN"|"TAKEN"|"CLOSED", "createdAt": String }

{ "id": String, "userId": String, "user": UserSummary, "title": String, "description": String?, "maxPrice": Double?, // IDR, optional "category": String?, "status": "OPEN"|"FOUND"|"CLOSED", "createdAt": String }

{ "id": String, "name": String, "email": String, "waNumber": String, "avatarUrl": String?, "createdAt": String }

Auth
POST /auth/register public Daftar akun baru
Request Body
{ "name": "Okta Pratama", // required "email": "okta@mail.com", // required, unique "password": "password123", // required "waNumber": "628123456789" // required, format intl }
Response 201
{ "accessToken": "eyJ...", // JWT 24 jam "user": UserDto }
POST /auth/login public Login, dapat token
Request Body
{ "email": "okta@mail.com", "password": "password123" }
Response 200
{ "accessToken": "eyJ...", "user": UserDto }
GET /auth/me 🔐 Auth Profil user dari token
Response 200
UserDto // data user yang sedang login

Jastip
📋 Tab "Tersedia", listing dari provider yang menawarkan jasa jastip. GET /jastip hanya return status ACTIVE.
GET /jastip public List semua jastip aktif
Response 200
[JastipDto, ...] // hanya status ACTIVE
GET /jastip/{id} public Detail satu jastip
Response 200
JastipDto // 404 kalau tidak ditemukan
POST /jastip 🔐 Auth Buka jastip baru
Request Body
{ "fromLocation": "Giant Dinoyo", // required "toLocation": "Kos Soekarno", // required "deadline": "2026-03-15T15:00:00", // required "latitude": -7.9666, // required "longitude": 112.6326, // required "notes": "Bisa groceries" // optional }
Response 201
JastipDto // include user object
PUT /jastip/{id} 🔐 Auth Update status (owner only)
Request Body
{ "status": "CLOSED" // ACTIVE | CLOSED }
Response 200
JastipDto // 403 kalau bukan owner
DELETE /jastip/{id} 🔐 Auth Hapus jastip (owner only)
Response 200
{ "message": "Jastip berhasil dihapus" } // 403 kalau bukan owner

Preloved
📋 Tab "Dijual", barang preloved yang dijual. GET /preloved hanya return status AVAILABLE.
GET /preloved public List semua barang tersedia
Response 200
[PrelovedDto, ...] // hanya status AVAILABLE
GET /preloved/{id} public Detail satu item
Response 200
PrelovedDto // 404 kalau tidak ditemukan
POST /preloved 🔐 Auth Post barang baru
Request Body
{ "title": "Nike Air Max 90", // required "description": "Jarang dipakai", // optional "price": 350000, // required, IDR "category": "FASHION", // required "condition": "GOOD", // required "imageUrl": "https://..." // optional }
Response 201 + Enums
PrelovedDto // condition: "NEW" | "LIKE_NEW" | "GOOD" | "FAIR" // status default: AVAILABLE
PUT /preloved/{id} 🔐 Auth Update status (owner only)
Request Body
{ "status": "SOLD" // AVAILABLE | SOLD | RESERVED }
Response 200
PrelovedDto // updated
DELETE /preloved/{id} 🔐 Auth Hapus item (owner only)
Response 200
{ "message": "Preloved berhasil dihapus" }

Requests
📋 Tab "Cari Jastip", user yang butuh dititipin bisa posting request. Provider lain bisa "ambil" request tersebut. GET /requests hanya return status OPEN.
GET /requests 🔐 Auth List semua request terbuka
Response 200
[RequestDto, ...] // hanya status OPEN
POST /requests 🔐 Auth Buat request jastip baru
Request Body
{ "fromLocation": "Alfamart Soekarno", // required "toLocation": "Kos Dieng Indah", // required "notes": "Indomie 3 bungkus" // optional }
Response 201
RequestDto // status: OPEN
PUT /requests/{id}/take 🔐 Auth Ambil request (provider)
Request Body
// tidak perlu body
Response 200
{ "request": RequestDto, // status: TAKEN "takenBy": UserSummary // provider yg ambil }
⚠️ 403 kalau mencoba mengambil request milik sendiri. 409 kalau request sudah diambil orang lain.
🔍
Wanted
📋 Tab "Barang Dicari", user yang mencari barang preloved bisa posting wanted. Seller yang punya barang bisa "fulfill" request tersebut. GET /wanted hanya return status OPEN.
GET /wanted 🔐 Auth List semua pencarian terbuka
Response 200
[WantedDto, ...] // hanya status OPEN
POST /wanted 🔐 Auth Post pencarian barang baru
Request Body
{ "title": "Laptop second 3 juta", // required "description": "RAM min 8GB", // optional "maxPrice": 3000000, // optional, IDR "category": "GADGET" // optional }
Response 201
WantedDto // status: OPEN
PUT /wanted/{id}/fulfill 🔐 Auth Tawarkan barang ke pencari
Request Body
// tidak perlu body
Response 200
{ "wantedItem": WantedDto, // status: FOUND "foundBy": UserSummary // seller yg offer }
⚠️ 403 kalau mencoba fulfill wanted milik sendiri. 409 kalau wanted sudah dipenuhi orang lain.
