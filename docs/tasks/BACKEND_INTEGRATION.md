## Kondisi Android saat pemeriksaan

Adapter dummy tetap default selama rangkaian integrasi belum selesai. Login/register/refresh/me/logout dan GET daftar sudah memiliki interface HTTP. Checkpoint berikutnya pada branch `codex/android-backend-records` menyambungkan GET detail, POST, PATCH dan DELETE melalui `RemoteActivityStore`; [bukti transport](../qa/iteration-2/BACKEND_RECORDS.md) mencakup 182 debug unit tests, termasuk 11 kasus baru. Kontrak core diperiksa ulang terhadap backend `28a3cb78031c1c60f687ab2567aa2a5c4de41260`.

`RemoteGuideStore` dan `UnconfiguredScanRepository` masih mengembalikan NOT_CONFIGURED. Branch lanjutan `codex/android-backend-summaries` menyediakan binding dashboard/statistik, 190 debug unit tests dan satu lifecycle native API 24 ke Go/PostgreSQL lewat SSH yang memeriksa perubahan agregat setelah simpan, edit satuan dan hapus; [bukti ringkasan](../qa/iteration-2/BACKEND_SUMMARIES.md). Beranda/Statistik/Profil remote masih perlu memakai model server tersebut. Cursor/filter riwayat dan penerimaan screen remote juga belum selesai. Mengganti flag adapter sekarang belum menghasilkan aplikasi remote yang lengkap. Build remote dalam checkpoint transport tidak mengubah default dummy pada source.

Gerbang perangkat, 5 November: GET metadata anonim dari emulator API 24 gagal pada handshake TLS. Bukti ClientHello dan uji host menunjukkan sertifikat gateway ECDSA P-384 tidak cocok dengan grup P-256 yang ditawarkan emulator. [Rincian dan reproduksi](../qa/iteration-2/BACKEND_RECORDS.md#uji-https-native-belum-lulus-pada-api-24) tetap menjadi syarat sebelum aktivasi remote. Pengguna mengonfirmasi panel Nginx Proxy Manager `proxy.bccdev.id` dikelola admin/tim BCC; `cp-bcc` hanya menangani HTTP di belakang gateway. Belum ada perubahan pada TLS server atau trust client. Backend terbaru saat pemeriksaan adalah `5cc59bc461b81c45e08878da2c44a8b3e9eef15b`; kontrak core dan handler catatan tidak berubah dari commit yang diuji.

## Urutan penyambungan dan penerimaan

1. **Kontrak core dan catatan.** Binding POST/GET detail/PATCH/DELETE serta unit transport sudah tersedia pada checkpoint catatan. UUID/payload draf, pembedaan 201/200, konflik idempotensi/versi, log terhapus, If-Match dan cancellation diuji. Transport tidak mereplay write ketika koneksi putus; sesi dapat mencoba lagi setelah 401 dengan credential baru dan payload yang sama. Pada 5 November, satu kasus lifecycle native API 24 terhadap Go/PostgreSQL lewat tunnel SSH lulus: register/login, create/replay/detail/daftar, edit/konflik, delete/replay, progres `/me` dan logout/revokasi. Akun fixture serta seluruh data turunannya dibersihkan. Ini belum penerimaan HTTPS publik atau screen remote; kompatibilitas TLS dan langkah 5 tetap terbuka.
2. **Sesi dan pemisahan akun.** Verifikasi refresh tunggal, token lama setelah rotasi, hasil refresh tidak diketahui, logout dan pembersihan credential/draf. Nama/zona berasal dari profil server; cursor dan cache terikat akun serta filter.
   Checkpoint `codex/android-write-outcome-recovery` memperbaiki NETWORK/TIMEOUT → retry 429/422: snapshot/UUID tetap terkunci, error terakhir tetap terlihat, dan guard diisi kembali dari draf hasil restart. Enam regresi baru, 196 unit serta 23 eksekusi native API 24 lulus, termasuk pause, force-stop proses dan replay tanpa duplikasi; [QA pemulihan](../qa/iteration-2/WRITE_RECOVERY.md). Penerimaan HTTP melalui screen dan seluruh gate perangkat tetap mengikuti langkah 5.
3. **Data layar.** Gunakan dashboard, statistics, progress dan waste-guide server. Agregat tidak dihitung dari satu halaman daftar berisi 20 item. Panduan kosong/PUBLISHED, loading, empty, refresh error dan retry memakai state nyata tanpa menggantinya dengan fixture sukses. Tambahkan pagination/cursor dan deduplikasi riwayat.
4. **AI melalui Go.** APK hanya memakai kontrak publik; Python/model/key Gemini tetap privat. Ikuti capability deteksi/rekomendasi, confirmed_object, input_source, context_revision, kondisi independen, risiko, READY/NEEDS_CONTEXT/UNAVAILABLE dan saran CONDITIONAL beserta conditions_to_verify. Satu label metode menggantikan kontrak alternatif lama. REDUCE pencegahan tetap melalui manual sampai provenance mendukungnya. Tidak auto-save atau memberi XP dari hasil scan.
5. **Penerimaan perangkat.** Jalankan register/login → catat → replay/timeout → detail/edit/konflik/delete → dashboard/statistik → pergantian akun/logout dengan backend, disertai pemeriksaan tema, teks besar dan navbar. Pisahkan bukti MockWebServer, backend/database dan perangkat. Jangan menyatakan integrasi selesai hanya dari readiness atau tes schema.

Base URL tetap konfigurasi build, bukan literal pada layar. Dokumentasikan konfigurasi yang benar-benar diuji sebelum mengubah adapter default; dummy tetap tersedia untuk pengembangan dan pengujian terisolasi, tanpa pintu masuk mode demo di produk. Backend dan deployment tidak diubah oleh checkpoint UI ini.
